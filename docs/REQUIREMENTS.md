# ScreenLink 需求文档

## 1. 项目概述

通过手机 App 远程控制 Windows 电脑截图，图片经局域网加密传输回手机端。电脑端后台隐蔽运行，手机端全流程控制（触发、查看、保存、分享）。

## 2. 用户与使用场景

- 用户在自己的 Windows 11 电脑与自己的安卓手机之间使用（家庭/办公室同一局域网）
- 典型场景：人不在电脑前，用手机查看电脑屏幕当前内容并留存截图
- 单电脑 ↔ 单手机为主，设计上预留多设备能力

## 3. 功能需求

### 3.1 电脑端（Windows 11，C++/Qt6）

| ID | 需求 | 优先级 |
|---|---|---|
| PC-01 | 系统托盘常驻，后台运行，无主窗口打扰；双击托盘打开设置窗口 | P0 |
| PC-02 | 设置窗口：配置监听端口、图片保存目录、JPEG 质量 | P0 |
| PC-03 | 截图区域预设：定义多个命名预设（位置 x/y + 宽高），支持"全屏"默认项；可视化拾取（拖拽选框） | P0 |
| PC-04 | 配对管理：生成配对码（含有效期）、显示二维码、已配对设备列表（查看/删除） | P0 |
| PC-05 | TCP 服务端监听，TLS 1.3 加密通信 | P0 |
| PC-06 | 收到手机截图指令 → 按指定预设截图 → JPEG 编码 → 回传 → 按配置目录本地保存 | P0 |
| PC-07 | 开机自启（可选开关，注册表 Run 键） | P1 |
| PC-08 | 多显示器支持（选择显示器编号） | P1 |
| PC-09 | 日志窗口/文件（不记录截图内容，仅记录连接与操作事件） | P2 |

### 3.2 安卓端（Android 8.0+，Kotlin）

| ID | 需求 | 优先级 |
|---|---|---|
| AN-01 | 首次启动引导页：PIN 输入 / 二维码扫码（V1.1）两种配对方式 | P0 |
| AN-02 | 已配对设备列表：显示电脑名/IP/状态，点击连接 | P0 |
| AN-03 | 连接后主界面：区域预设下拉选择（含"全屏"）+ 截图按钮 | P0 |
| AN-04 | 截图结果展示：大图预览，可缩放 | P0 |
| AN-05 | 历史记录：本地 SQLite/文件保存历史截图（缩略图列表 → 大图） | P0 |
| AN-06 | 保存到系统相册（MediaStore）+ 系统分享（Intent） | P0 |
| AN-07 | 连接状态指示：在线/离线/配对失败，自动重连（指数退避） | P1 |
| AN-08 | JPEG 质量、连接超时等设置项 | P2 |

### 3.3 通信与安全

| ID | 需求 | 优先级 |
|---|---|---|
| SE-01 | 配对码 32 字节随机（8 位可读 Base32），10 分钟有效期，错误 3 次拉黑 5 分钟 | P0 |
| SE-02 | TLS 1.3 传输加密；手机端证书固定（配对时记录证书指纹） | P0 |
| SE-03 | 消息序号 + 时间戳防重放 | P0 |
| SE-04 | 手机端未触发时，电脑端零屏幕采集（隐私硬约束） | P0 |
| SE-05 | 已配对设备免密重连（设备 ID + 信任列表） | P1 |

## 4. 非功能需求

| 项 | 要求 |
|---|---|
| 性能 | 截图→编码→回传端到端 ≤1.5s（1080P 全屏，千兆局域网） |
| 兼容性 | 电脑端 Win10/11；安卓 minSdk 26（Android 8.0，覆盖 98%+ 设备），targetSdk 34 |
| 资源占用 | 电脑端空闲时内存 <80MB，CPU ≈0（无轮询采集） |
| 健壮性 | 手机断线/电脑重启后自动恢复；异常断开不崩溃 |
| 代码质量 | 双端协议实现共用 PROTOCOL.md 单一规范；关键路径单元测试 |

## 5. 验收标准（MVP）

1. 电脑端安装后托盘常驻，无窗口自动弹出
2. 手机 PIN 配对成功 → 连接成功 → 触发截图 → 手机收到并显示图片 ≤1.5s
3. 电脑本地按配置目录保存同一张图
4. 手机历史记录可回看、可保存相册、可分享
5. 未配对手机无法连接；配对码错误 3 次被拉黑
6. 手机不触发时，电脑端无任何截屏行为（可通过日志/进程行为验证）

## 6. 明确不做（当前版本）

- ❌ 手机远程控制鼠标键盘（远程桌面形态）
- ❌ 实时视频流/录屏（V2 预留协议扩展位）
- ❌ 跨互联网传输（仅局域网）
- ❌ iOS 端（协议层已语言无关化，未来可扩展）
